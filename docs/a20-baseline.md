# SOtM Eunhasu A20 baseline

Collected from the original SOtM Eunhasu A20 system.

- Kernel release: `6.2.15-215.fc36.armv7hl`
- Kernel-devel source directory used for collection:
  `/tmp/eunhasu-kernel/extracted/usr/src/kernels/6.2.15-215.fc36.armv7hl`
- Diretta modules:
  - `modules/diretta/alsa_bridge.ko`
  - `modules/diretta/diretta_direct.ko`

## Repository layout

- `config/eunhasu-a20.config`: original SOtM kernel configuration.
- `baseline/a20/kernel-devel/`: archived matching kernel-devel tree.
- `baseline/a20/metadata/`: Module.symvers, generated headers and host/kernel metadata.
- `baseline/a20/rpm/`: original kernel-devel RPM, if it was present.
- `modules/diretta/`: original binary modules and inspection records.

This is a baseline collection, not a complete kernel source tree.
No Raspberry Pi 2 configuration or build output is generated by this script.
